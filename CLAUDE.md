# Claude Instructions

Dieses Projekt dient dem Erlernen von Scrum anhand eines Mini-Taskboards.




Lies zuerst die `README.md`, bevor du Anforderungen, User Stories,
Akzeptanzkriterien oder Code erzeugst.

Nutze die `README.md` als fachlichen Kontext für das Projekt.




## Arbeitsweise

- Scrum und das Rollenverständnis stehen im Vordergrund.
- Erzeuge nicht ungefragt vollständige Implementierungen.
- Unterstütze zunächst bei Anforderungen, User Stories und Akzeptanzkriterien.
- Produktentscheidungen trifft das Scrum Team, nicht die AI.
- Schlage keine Features außerhalb des definierten Scopes vor, außer sie werden ausdrücklich angefordert.
- Formuliere User Stories im Format:
  "Als ... möchte ich ..., damit ..."
- Akzeptanzkriterien sollen konkret, überprüfbar und möglichst technologieunabhängig sein.
- Trenne fachliche Anforderungen von technischen Implementierungsdetails.
- Wenn Anforderungen unklar sind, benenne die Unklarheit statt sie stillschweigend zu erfinden.
